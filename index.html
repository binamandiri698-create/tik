Alur Kerja Sistem Komputer (Siklus Data)

Klik pada setiap tahapan alur di bawah ini untuk melihat penjelasan lengkap cara kerja data di dalam komputer:

1. INPUT

Memasukkan data/perintah (Keyboard, Mouse, Mic)

2. PROCESS

Menganalisis & mengolah data (Processor CPU, RAM)

3. OUTPUT

Menampilkan hasil olahan (Monitor, Printer, Speaker)

4. STORAGE

Menyimpan data secara permanen (SSD, HDD, Flashdisk)

Petunjuk:

Klik salah satu tahapan kotak di atas untuk menampilkan penjelasan mendalam!

1. Hardware (Perangkat Keras)

Komponen fisik yang bisa disentuh & dilihat

Hardware bertugas melaksanakan fungsi input, pemrosesan, penyimpanan, dan output data secara elektronik.

Input Device (Perangkat Masukan)

Keyboard, Mouse, Scanner, Microphone, Webcam.

Process Device (Perangkat Pemroses)

CPU (Otak Komputer), RAM (Memori Utama), Motherboard.

Output Device (Perangkat Keluaran)

Monitor, Printer, Speaker, Proyektor.

Storage Device (Perangkat Penyimpanan)

Harddisk (HDD), Solid State Drive (SSD), Flashdisk.

2. Software (Perangkat Lunak)

Program dan instruksi non-fisik komputer

Software tidak dapat disentuh secara fisik. Berfungsi sebagai jembatan interaksi antara manusia dengan perangkat keras.

Sistem Operasi (Operating System)

Pengelola utama komputer: Windows, Linux, macOS, Android.

Software Aplikasi (Application)

Program khusus tugas: Ms Office, Chrome, Canva, Photoshop.

Software Utilitas (Utility)

Perawatan komputer: Antivirus (Avast), Disk Cleaner, WinRAR.

Brainware (Pengguna)

Manusia yang mengoperasikan komputer: Programmer, Operator, User.
